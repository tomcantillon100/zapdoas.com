Heatwave Classroom Micro:bit Project

Investigation

Hot classrooms can make it harder for students and teachers to feel comfortable while learning.

I am exploring how a Micro:bit could help measure the temprature in a classroom. A study found a link between classroom temperature and students' test scores. It looked at classroom temperature and ventilation.

Design: inputs and outputs

The Micro:bit checks the temperature near the device. It then shows a number and a simple face on its LED lights. The example alert point is 28°C. This is just a setting for my project, not an official safety limit.

PartWhat it does
Input: built-in temperature sensorReads the temperature around the Micro:bit.
Decision: my programChecks whether the reading is 28°C or higher.
Output: built-in LED lightsShows the temperature, then a sad face if it is at least 28°C, or a happy face if it is lower.

One thing to remember: The sensor measures the Micro:bit's own board, so sunlight or heat from the device can change the reading. Put it in a shady place and treat the number as an estimate.

Wiring diagram

I don't need extra wires for this version because the temperature sensor and LED lights are already inside the Micro:bit.

Temperature sensor (input) → Micro:bit program (decision) → LED lights (output)

How the program decides

  1. Start the program.
  2. Read the temperature.
  3. Show the temperature number.
  4. If it is 28°C or more, show a sad face. If not, show a happy face.
  5. Wait five seconds, then do it again.

My code

This is MakeCode JavaScript. The comments are notes that explain what each part does.

// Keep repeating the code inside these curly brackets.
basic.forever(function () {
  // Get the temperature in Celsius and save it in a variable.
  let temp = input.temperature()

  // Show the temperature number on the Micro:bit.
  basic.showNumber(temp)

  // Check if the temperature is 28 or higher.
  if (temp >= 28) {
    // Show a sad face when it is warm.
    basic.showIcon(IconNames.Sad)
  } else {
    // Otherwise show a happy face.
    basic.showIcon(IconNames.Happy)
  }

  // Wait five seconds before checking again.
  basic.pause(5000)
})
